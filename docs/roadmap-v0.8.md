# Hoja de ruta histórica (v0.8)

El proyecto ha evolucionado desde esta planificación inicial. La hoja de ruta actual y verificable se mantiene en **[v0.10](roadmap-v0.10.md)**, que incluye las capas NASA implementadas, las 2.568 especies ECOCROP importadas, el módulo SRTM y las pruebas.

No interpretes la implementación del catálogo o los mapas visuales como una validación agronómica o de parcela. Las tareas que dependen de datos espaciales GAEZ, NDVI Sentinel-2 procesado y pruebas con agricultores continúan abiertas.
