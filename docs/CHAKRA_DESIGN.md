# CHAKRA — identidad y experiencia del agricultor

Nombre público: CHAKRA; logo tipográfico `chakra`. Se conserva Wilder-reyes/TERRA360-AI y los IDs/claves históricas para compatibilidad, trazabilidad y recuperación de datos guardados.

Diseño autorizado: negro verdoso #050806, acento #D6F866, tarjetas rgba(17,22,18,.6), vidrio moderado, Inter variable local y PT Serif 400 italic para la palabra destacada. Iconos Lucide registrados localmente mediante iconify-icon; no se consultan APIs de iconos en el navegador. Foco visible, contraste verificado, objetivos táctiles y movimiento reducido. Los colores de productos NASA y las bandas HLS no cambian por branding.

Portada: hero → tres tarjetas con miniaturas ilustrativas → cuatro pasos → garantías explicativas sin testimonios fabricados → CTA → fuentes consultadas, sin sugerir patrocinio. El CTA abre la parcela de estudio y retira la portada para que el agricultor complete el recorrido sin distracciones. Las miniaturas no representan mediciones ni predicciones.

Texto: una acción por pantalla, registrar cultivo y mes, comparar agua/cobertura, diferencias «Sin cambio» y porcentajes «menos/más». BIO sigue como guía breve, no chatbot. PDF blanco A4 y enlaces para compartir llevan CHAKRA.

Activo decorativo: frontend/public/chakra-fields.webp, 1536×1024, aproximadamente 127 kB, optimizado desde una imagen generada para el proyecto. No es fotografía georreferenciada ni evidencia de la parcela. Prompt: «premium website background photograph, irrigated agricultural fields on Peru's arid Pacific coast, early sunrise, dark olive greens, negative space for white text, no people/text/logos/UI/data overlays». Fuente: generación de imagen integrada, no una descarga NASA.

Despliegue: mismo frontend Vercel y proxy /api al backend Render verificado. No cambian rutas ni requerimientos de credenciales científicas.
